Setup Required

To use this app, you need to configure Google OAuth credentials:

  1. Go to Google Cloud Console
  2. Create a new project or select existing
  3. Enable YouTube Data API v3, Google Sheets API, and Google Drive API
  4. Create OAuth 2.0 credentials (Web application)
  5. Add redirect URI: http://localhost:5000/oauth/callback
  6. Open credentials.py and paste your Client ID and Client Secret

Credentials Configuration

Edit credentials.py to configure your API keys:

Variable Description Required
GOOGLE_CLIENT_ID Google OAuth Client ID from Cloud Console
GOOGLE_CLIENT_SECRET Google OAuth Client Secret from Cloud Console
ENCRYPTION_KEY Fernet key for token encryption (auto-generated if empty) Auto
SESSION_SECRET Flask session secret (auto-generated if empty) Auto
Tip: Copy credentials_example.py to credentials.py and fill in your values. The ENCRYPTION_KEY and SESSION_SECRET will be auto-generated on first run if left empty.
